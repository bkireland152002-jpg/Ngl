# Gowri Menon – Art Folio

A single-page gallery of seventeen works across four media: pencil, opaque watercolour, digital painting, and pen and ink.

- `index.html` – the whole site (no build step)
- `art/` – the artwork images

Filter by medium with the bar at the top; select any piece to view it full screen (arrow keys or swipe to move between works).

All works © Gowri Menon.
